# Spacing

The old app's 5px grid plus 8px. Tokens are named after their pixel value; layouts use the
semantic ones (`gutter`, `section`, `stack` and `nav`, all in `semantic-tokens.ts`).

{['5', '8', '10', '15', '25'].map((size) => (

  <div key={size} style={{ display: 'flex', alignItems: 'center', gap: 16, marginBottom: 8 }}>
    <code style={{ width: 48 }}>{size}</code>
    <div
      style={{
        width: token.var(`spacing.${size}`),
        height: 16,
        background: token.var('colors.accent.default'),
      }}
    />
  </div>
))}
