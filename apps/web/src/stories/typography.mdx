# Typography

Avenir at an 18px root size. Headings get their text styles (`theme/text-styles.ts`) from the
global CSS, so plain `h1`–`h3` are styled; `body.small` is for dates, hints and errors, usually
with the `muted` layer style.

## Text styles

<Unstyled>
  <h1>Score erfassen (heading.page)</h1>

## Font sizes

Relative to the 18px root (`theme/tokens.ts`), so they scale with the text around them. `xl`
and `5xl` are the duel scores, `headerIcon` the header's icons.

<Unstyled>
  {['sm', 'md', 'lg', 'xl', '2xl', 'headerIcon', '4xl', '5xl'].map((size) => (
    <div key={size} style={{ display: 'flex', alignItems: 'baseline', gap: 16, marginBottom: 8 }}>
      <code style={{ width: 96, fontSize: 14 }}>
        {size} · {token(`fontSizes.${size}`)}
      </code>
      <span style={{ fontSize: token.var(`fontSizes.${size}`) }}>BSZZ Dojo 6 : 2</span>
    </div>
  ))}
</Unstyled>

## Weights and line heights

`normal` (400) and `bold` (700); line heights `none` (1, big figures like the duel score),
`snug` (1.2, headings) and `normal` (1.43, body text).
